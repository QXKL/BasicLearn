# 第 003 节: 5 种常见通知

## 1. `@Before`

目标方法执行之前运行。

适合做:

- 参数日志
- 权限预检查
- 调用前提示

## 2. `@After`

目标方法结束后运行。

注意: 不管方法成功还是异常, 它都会执行。

## 3. `@AfterReturning`

只有方法**正常返回**时才执行。

适合做:

- 打印返回值
- 记录成功结果

## 4. `@AfterThrowing`

只有方法**抛异常**时才执行。

适合做:

- 记录异常
- 失败告警

## 5. `@Around`

功能最强, 它能把整个目标方法包起来。

你可以在里面:

- 调用前打印日志
- 控制是否继续执行目标方法
- 拿到返回值
- 统计耗时
- 捕获异常后再处理

## 学习建议

初学时先把 `@Before`、`@AfterReturning`、`@AfterThrowing` 看熟。

`@Around` 最强, 也是最容易绕晕的一个。
