# AOP 学习路线

这部分按小节推进，每次只学一个核心点。

## 目录安排

- `aop_quick_start_000`: AOP 快速入门示例
- `aop_intro_001`: AOP 是什么
- `aop_core_concepts_002`: AOP 的 3 个核心概念
- `aop_five_advices_003`: 5 种常见通知
- `aop_pointcut_execution_004`: 切点表达式 `execution`
- `aop_advice_order_005`: 通知执行顺序与异常
- `aop_use_cases_006`: AOP 常见应用场景与注意事项

## 学习建议

先看 `000` 和 `001`，建立直觉。

再看 `002`、`003` 和 `004`，理解概念和写法。

最后看 `005` 和 `006`，掌握执行细节和实际使用边界。
