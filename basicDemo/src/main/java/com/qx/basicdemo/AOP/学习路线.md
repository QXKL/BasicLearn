# AOP 学习路线

这部分按小节推进，每次只学一个核心点。

## 第一阶段：建立直觉

- `aop_000_quick_start`: AOP 快速入门示例
- `aop_001_intro`: AOP 是什么
- `aop_002_core_concepts`: AOP 的 3 个核心概念
- `aop_003_five_advices`: 5 种常见通知
- `aop_004_pointcut_execution`: 切点表达式 `execution`
- `aop_005_advice_order`: 通知执行顺序与异常
- `aop_006_use_cases`: AOP 常见应用场景与注意事项

## 第二阶段：进入底层机制

- `aop_007_joinpoint_target_proxy_weaving`: Join Point、Target、Proxy、Weaving
- `aop_008_jdk_proxy_vs_cglib`: JDK 动态代理 vs CGLIB
- `aop_009_execution_advanced`: `execution` 进阶
- `aop_010_within_this_target_args`: `within`、`this`、`target`、`args`
- `aop_011_annotation_pointcuts`: `@annotation`、`@within`、`@target`
- `aop_012_multiple_aspects_order`: 多切面与 `@Order`

## 第三阶段：开始实战和排错

- `aop_013_custom_annotation_practice`: 自定义注解 + AOP 实战
- `aop_014_self_invocation_failure`: 自调用为什么会让 AOP 失效
- `aop_015_transactional`: `@Transactional` 和 AOP
- `aop_016_debugging_checklist`: AOP 失效场景排查清单

## 学习建议

先完成 `000` 到 `006`，把基础直觉打牢。

再进入 `007` 到 `012`，把代理、匹配规则和多切面顺序建立起来。

最后看 `013` 到 `016`，把 AOP 放进真实开发问题里理解。
