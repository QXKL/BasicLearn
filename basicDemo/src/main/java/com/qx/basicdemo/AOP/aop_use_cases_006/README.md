# 第 006 节: AOP 常见应用场景与注意事项

## 常见应用场景

- 日志记录
- 权限校验
- 事务控制
- 接口耗时统计
- 异常统一处理

## 什么时候适合用 AOP

当一段逻辑会在很多方法里重复出现时, AOP 很适合。

例如:

- 每个接口都要记录访问日志
- 每个业务方法都要统计耗时

## 什么时候别硬用 AOP

如果某段逻辑只服务于一个方法, 而且和业务强相关, 直接写在业务里可能更清晰。

AOP 不是为了“看起来高级”, 而是为了减少重复、增强可维护性。

## 初学者常见坑

- 以为加了切面注解就一定生效
- 不清楚切点到底拦了哪些方法
- 把 `@After` 和 `@AfterReturning` 混在一起
- `@Around` 里忘了调用 `proceed()`
